# 欢迎来到龙高北小站

欢迎使用龙高北小站！

龙高北小站是一个面向龙高北同学的校园交流平台，你可以在这里分享学习经验、记录校园生活、浏览学校大事记，也可以通过表白墙表达自己的心意。

如果你是第一次来到这里，可以先阅读下面几篇文档，它们会帮助你快速熟悉本站。

---

## 🚀 快速开始

如果你是第一次使用本站，建议按照下面的顺序阅读：

* 注册账号
* 登录账号
* 发布第一篇帖子
* 修改个人资料

几分钟内，你就可以完成全部基础设置。
