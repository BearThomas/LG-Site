# 帮助中心

这里是龙高北小站的帮助文档。你可以在 `doc/` 文件夹里新增或编辑 Markdown 文件，帮助页面会根据生成的目录清单自动展示。

## 如何新增页面

1. 在 `doc/` 下创建一个 `.md` 文件。
2. 文件里的第一个 `# 标题` 会作为目录标题。
3. 如果需要控制顺序，可以在文件开头加 front matter：

```md
---
title: 页面标题
order: 10
---
```

## 目录规则

子文件夹会自动成为左侧目录。例如：

```text
doc/
  posts/
    create-post.md
```

会在帮助页里显示为 `posts / create-post` 的层级。
